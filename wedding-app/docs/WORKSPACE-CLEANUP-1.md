## What was removed (all untracked runtime artifacts — nothing tracked was deleted)
- `server/uploads/public/` — **95 MB** of org-logo uploads accumulated by e2e
  runs. `fileStorage.ts` recreates the dirs at boot; uploads are per-deployment
  data, never source.
- `server/uploads/private/` — couple document uploads from e2e runs (same
  rationale).
- `server/data/wedding.db{,-wal,-shm}` — **6.5 MB** runtime SQLite DB.
  Regenerated by `npm run migrate && npm run seed`.
- `client/test-results/` + `playwright-report/` — Playwright run artifacts.
- Stale `.a11y-event-id` marker files.
- `.git` compaction: `git gc --prune=now` reclaimed ~9 MB by pruning the
  unreachable intermediate commits replaced during the `d019f27` squash
  (all of their content lives in `d019f27`, which is pushed everywhere).

## What was deliberately KEPT
- `client/e2e/mobile-visual.mobile-visual.spec.ts-snapshots/` (8.7 MB, 24 PNGs)
  — committed baselines for the `mobile-visual-test.sh` visual-regression
  gate; removing them would break that suite.
- Self-hosted fonts in `client/public/fonts/` (~1 MB) — required for the
  CSP-clean brand typography.
- `uploads/GH_TOKEN.txt` (workspace root) — required for GitHub pushes.
- All docs under `wedding-app/docs/`, scripts, configs.
