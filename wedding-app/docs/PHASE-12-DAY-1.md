To close out advanced digital operations, we built a fully integrated WYSIWYG Invitation Builder simulating outgoing guest deliveries.

## What's Built
- **`EventInvitesTab.tsx`**: Constructed a robust double-panel view added to the Event Hub replacing manual invite generation.
  - **The Builder View**: A structural editor allowing Planners to seamlessly select a master Theme (`Formal`, `Modern`, `Garden`) completely reskinning the active preview container mapping font stacks and dynamic gradient bindings automatically!
  - Content Blocks are entirely fluid. Planners can add, delete, edit, and move `Text`, `Images`, `Buttons`, `Map Links`, and `Schedule` items vertically, reflecting instantly on the canvas.

  - The second interactive panel actively hits the `sdk.guests.list` arrays.
  - Generates a "Send to Guests" function dynamically triggering dispatch simulations, turning tracked status blocks from `Not Sent` directly to `Sent` or `Opened`. 
  - Planners can grab the native `Unique Link` tailored securely per guest resolving RSVP identity immediately skipping login blocks securely. 
- **Exporting Modules**: Built physical string-parsing generating a completely native responsive `HTML` payload download mapping all configured arrays, css injection, and layout wrappers, providing venue owners direct HTML codes they can drop into Mailchimp!
